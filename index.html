About

Unofficial 5x4 keycard helper for playing Codenames: Pictures with Codenames: Duet rules.

Use LOCK before passing the device. Copy the Session ID to restore the same keycard later.

Please playtest and leave feedback on BGG or Reddit.

Not affiliated with Czech Games Edition. Codenames and related marks belong to their respective owners.

Setup: use 20 Codenames: Pictures cards in a 5x4 grid.

Start with 7 time tokens. Use 8 tokens for an easier first play.

Each player sees 7 agents, 2 assassins, and 11 non-agents. Win by finding all 12 unique agents.

The hidden matrix is:

  • 2 shared agents
  • 4 Alpha-only agents
  • 4 Bravo-only agents
  • 1 Alpha agent / Bravo assassin cross-risk
  • 1 Bravo agent / Alpha assassin cross-risk
  • 1 mutual assassin
  • 7 bystanders

Play like Codenames: Duet. When time tokens are gone, sudden death begins: no more clues, and any wrong guess loses.
